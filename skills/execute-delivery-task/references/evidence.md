# Task Evidence

Record:

- task and requirement IDs
- integration starting revision
- changed paths
- acceptance criterion to evidence mapping
- commands run with pass, fail, or skipped status
- migration or generated-artifact results
- bounded amendments and their approval artifacts
- known limitations and remaining risks
- commit and pull-request identifiers when authorized

Evidence must be reproducible and concise. Never include secrets, raw client data, or
`.env` contents.
